# ホームページ制作サービス仕様

## Webスタートプラン

- 初期制作費：0円
- 月額：9,800円（税込）
- 最低利用期間：24か月
- 24か月総額：235,200円（税込）
- 24か月経過後：1か月単位で自動更新
- 解約申出期限：次回決済日の10日前まで
- 24か月経過後の解約金：なし
- 24か月未満の中途解約金：残契約月数×9,800円（税込）
- 支払い：Stripeによるクレジットカード自動決済を予定

「初期制作費0円／月額9,800円／最低利用期間24か月／24か月総額／更新・解約条件」を、料金ページと申込最終確認画面で確認できるようにする。

## 基本制作範囲

- テンプレートまたは共通設計を活用
- 最大4ページ
- スマートフォン、タブレット、PC対応
- 問い合わせフォーム、電話発信ボタン
- Googleマップ、Instagram、X、公式LINE導線
- 営業時間、所在地、定休日、サービス内容
- 基本SEO、OGP、favicon、SSL、アクセス解析初期設定

構成例はトップ、サービス、事業者紹介、アクセス、問い合わせ。業種に合わせて調整する。

## 多言語ページ制作（標準範囲）

- 各プランのページ数上限内で、英語1言語分のAI翻訳ページ制作を標準対応とする（追加料金なし）
- 対象は原則、既存の日本語ページと同一の情報（メニュー・料金・アクセス・営業時間・支払い方法・予約方法・利用時の注意事項等）
- 単純な自動翻訳の貼り付けではなく、外国人のお客様が知りたい情報を整理して掲載する
- 英語ページの公開後の軽微な修正は、月額内の軽微な更新枠（月1回・15分以内等）に含む
- 中国語（簡体字）・韓国語への対応、ネイティブ翻訳者による校正、専門性の高い文書翻訳、ページ数上限を超える追加翻訳は別途見積もり

## 公開後の管理

- 基本サーバー利用料、SSL、バックアップ
- 稼働確認、軽微な表示崩れや不具合の修正
- 基本的なセキュリティ対応
- 問い合わせフォームの動作確認
- メール・チャットでの基本サポート
- 営業時間内に順次対応。24時間365日の即時対応は保証しない

## 月額内の軽微な更新

- 月1回まで
- 合計作業時間15分程度まで
- 文章、営業時間、定休日、住所、電話、写真、料金、メニュー、リンク、お知らせの軽微な変更

無制限更新とは表示しない。

## 別途見積もり

- 大幅なページ追加、全面リニューアル、大量更新
- 予約、決済、会員、EC、独自システム、API連携
- 中国語（簡体字）・韓国語ページの追加、ネイティブ翻訳者による校正、専門文書翻訳（英語1言語のAI翻訳ページは標準対応。詳細は「多言語ページ制作（標準範囲）」参照）
- ロゴ、撮影、動画、取材、原稿、高度なSEO、広告、SNS投稿代行
- Googleビジネスプロフィールの継続運用、現地訪問、緊急対応
- 月1回・15分を超える更新

軽微な追加更新は5,500円から。他は内容に応じて見積もる。

## ドメインとサーバー

- 独自ドメインの取得・更新費は原則お客様負担
- ドメイン名義は原則お客様
- 取得・初期設定を支援可能
- 基本サーバーは月額内
- 大量アクセス、大容量データ、特殊構成は別途費用の可能性あり
