# ChatGPT 画像生成プロンプト集（ブランド猫）

> **使い方**: ChatGPT に**運営者の猫写真を添付**したうえで、各プロンプトを貼り付けて生成する。
> 生成物は WebP 化（favicon は PNG）して `public/images/generated/` に保存し、
> `src/config/images.ts` のパスを実ファイルへ差し替えると、サイト内蔵の SVG イラストから自動的に置換される。
> OpenAI API キーはこの環境に未設定のため、API 生成は行わずプロンプト集のみ納品（指示書 9-3 準拠）。

## 全プロンプト共通の必須指定（毎回プロンプト末尾に付ける）

```text
【キャラクター統一条件（必ず維持）】
添付した猫写真と同一個体に見えること。白〜クリーム色の柔らかい毛並み。
耳・顔まわり・しっぽに淡いベージュ〜オレンジのポイントカラー。大きく丸い瞳。小さなピンクの鼻。
きょとんとした優しい表情。細長く上品な体つき。
スタイル: ミニマルで上品なフラット寄りイラスト。線は細く、色数は少なく、やわらかい陰影。
背景は明るいオフホワイト（#faf9f6）、差し色は淡ブルー（#dfeef7）とネイビー（#15365c）。
【禁止】文字・ロゴ・透かし / リアル写真風 / 別の猫種・毛色に見える描写 / 子ども向けアニメ調 / 過剰な装飾
```

## 個別プロンプト

### 1. hero-cat-working.webp（ヒーロー）
```text
添付の猫写真をモチーフにした、可愛いが上品で子どもっぽすぎないイラストを生成してください。
シーンは、ノートパソコンを使って楽しそうに仕事をしている様子。机の上は整っていて、
Web制作とAI支援会社のホームページのヒーロー画像として使える、ミニマルで洗練された雰囲気。
縦長 4:5。余白を広めに取り、猫は画面中央やや下に配置。
```
（+ 共通指定）

### 2. cat-web-design.webp
```text
同じ猫キャラクターが、画面にホームページのワイヤーフレームが表示されたモニターの前で
レイアウトブロックをそっと前足で置いているイラスト。正方形。
```

### 3. cat-ai-support.webp
```text
同じ猫キャラクターが、淡く光る小さなAIアシスタント（抽象的な光の球や吹き出し）と
並んで作業しているイラスト。未来的すぎず、やわらかい表現。正方形。
```

### 4. cat-line-support.webp
```text
同じ猫キャラクターが、スマートフォンのチャット吹き出し（無地・ロゴなし）を見ながら
丁寧に返信しているイラスト。正方形。
```

### 5. cat-google-map.webp
```text
同じ猫キャラクターが、ピンの立った抽象的な地図（実在サービスのロゴ・UIは描かない）を
指し示しているイラスト。正方形。
```

### 6. cat-sns-support.webp
```text
同じ猫キャラクターが、写真カードやハートの浮かぶ抽象的なSNS投稿画面を整えているイラスト。
実在SNSのロゴは描かない。正方形。
```

### 7. cat-data-analysis.webp
```text
同じ猫キャラクターが、上向きの折れ線グラフと棒グラフの前でメガネをかけずに
真剣な表情で資料を確認しているイラスト。正方形。
```

### 8. cat-local-support.webp
```text
同じ猫キャラクターが、小さな商店の店先（のれん・植木鉢のあるやさしい街並み）で
店主のそばに寄り添って立っているイラスト。横長 3:2。人物の顔は簡略化。
```

### 9. cat-cta-wave.webp
```text
同じ猫キャラクターが、片方の前足を上げてこちらに手を振っている、親しみやすいイラスト。
「相談してみよう」と思える歓迎の雰囲気。正方形。
```

### 10. cat-404.webp
```text
同じ猫キャラクターが、少し首をかしげて「あれ？」という表情で迷っているイラスト。
404ページに使えるよう、余白を活かしたシンプルな構図。正方形。
```

### 11. og-brand-cat.webp（OGP 1200×630）
```text
同じ猫キャラクターを右側 1/3 に配置し、左 2/3 はオフホワイトの無地余白
（あとから日本語のサイト名テキストを重ねるスペース）にした横長ブランドビジュアル。
下辺に淡ブルーの緩やかな帯。1200×630。
```

### 12. favicon-cat.png（512×512）
```text
同じ猫キャラクターの「顔だけ」を極限までシンプルにしたアイコン。
16px に縮小しても耳・ポイントカラー・表情が判別できる太めの形状。背景は透過。512×512 PNG。
```

### 13. logo-cat-mark.svg（ロゴマーク）
```text
同じ猫キャラクターの顔と片方の前足（そっと差し出す「猫の手」）を組み合わせた
ミニマルなロゴマーク。単色ネイビー（#15365c）版と、毛色フルカラー版の2案。背景透過。
```

### 14. cat-footer-sitting.webp
```text
同じ猫キャラクターが、しっぽを前足に巻いてきちんと座り、こちらを穏やかに見ているイラスト。
小さく表示されるため、シルエットが明快な構図。正方形。
```

### 15. flow-cut-01〜08.webp（8点セット）
```text
同じ猫キャラクターによる、ホームページ制作の流れを表す8枚の小さなカットイラストを、
同一タッチ・同一サイズで生成してください。
①メールを受け取る ②ヒアリングでメモを取る ③写真と原稿を受け取る ④初稿を組み立てる
⑤お客様と画面を確認する ⑥修正する ⑦公開ボタンを押す ⑧納品して見送る
各 400×400。アイコンとして使えるシンプルさを最優先。
```

## 品質チェックリスト（生成後）

- [ ] 全画像で同一個体に見える（毛色・耳・瞳・鼻・体型）
- [ ] タッチ・線の太さ・色数が統一されている
- [ ] 文字・透かし・実在サービスのロゴが入っていない
- [ ] WebP 変換・想定解像度・ファイル名が一覧と一致
- [ ] `src/config/images.ts` のパス差し替えとローカル表示確認
