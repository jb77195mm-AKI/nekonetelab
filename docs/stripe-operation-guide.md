# Stripe運用ガイド

## 日常確認

- 新規Subscription
- 支払い済みInvoice
- 支払い失敗
- 解約・更新状態
- Customer Portalの利用状況

カード番号、セキュリティコード、完全な有効期限を保存・記録しない。

## 支払い失敗

1. Stripe Dashboardで状態を確認
2. 顧客へ支払い方法更新を案内
3. Customer Portalを案内
4. 猶予期間中は状況を記録
5. 決済失敗直後にサイトを自動停止しない

長期間支払いが確認できない場合の保守停止・公開停止条件は契約書で確定する。

## 解約

Webスタート初期費用0円型は最低利用期間24か月。期間内の中途解約金は、残契約月数×9,800円（税込）。24か月経過後は1か月単位で自動更新し、解約金はない。解約申出期限は次回決済日の10日前。

Webスタート月額負担軽減型、Webサポート、DX関連サービスは、個別契約で確定した条件を確認してから解約処理を行う。

Portalで即時解約を許可する前に、以下を確認する。

- 解約申請期限（初期費用0円型：次回決済日の10日前）
- 中途解約金（初期費用0円型：残契約月数×9,800円・税込）
- サイト公開終了日
- ドメイン
- データ移管
- 返金

## 情報源

本デモには顧客DBを追加していない。Stripe Dashboardを一次情報源とする。

本番DBを追加する場合は、イベントIDの永続化、Subscription状態、期間、支払い状態、監査ログ、保存期間を設計する。
