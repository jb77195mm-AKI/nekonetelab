# デザインシステム

コンセプト: **地域の小さな会社に、WebとAIの頼れる右腕を。**
猫をブランドモチーフにした、地域密着型のWeb・AI・DX支援会社（かわいいが子どもっぽくない）。

## カラートークン（globals.css の @theme。Tailwind クラス名として使用可能）

| トークン | 値 | 用途 |
|---|---|---|
| `--color-paper` | `#faf9f6` | ページ背景（オフホワイト） |
| `--color-cream-light` | `#faf4e9` | 暖色セクションの淡背景（旧 orange-50 の置換先） |
| `--color-navy` | `#15365c` | 濃ネイビー（主ボタン・アイコン、旧 orange-700/600） |
| `--color-navy-deep` | `#0d2745` | ホバー・ダークセクション（旧 orange-800〜950 / bg-slate-950） |
| `--color-mist` | `#dfeef7` | 淡ブルー面 |
| `--color-mist-light` | `#eef6fa` | 淡ブルー面（さらに淡） |
| `--color-amber-accent` | `#d89a43` | 琥珀（おすすめプラン枠・重要数値、旧 orange-400） |
| `--color-amber-soft` | `#e9c07e` | ダーク面上の琥珀テキスト（旧 orange-300） |
| `--color-cat-cream` | `#f3e7d4` | 猫の毛色クリーム（淡枠、旧 orange-100） |
| `--color-cat-beige` | `#e4c7a2` | 猫のポイントカラー（枠線、旧 orange-200） |
| `--color-cat-nose` | `#cf7f7b` | 猫の鼻 |
| `--color-cat-bluegray` | `#91a9bd` | 差し色ブルーグレー |

無彩色（slate）と青系（sky）は Tailwind 既定のまま使用する。ダーク面の背景のみ
`bg-navy-deep` に統一。ヒーロー等のグラデーション hex は `#faf6ee` / `#eef6fa`。

琥珀（accent）の使用は「AI」表記・重要数値・モニター価格・小さなアクセント・ホバー補助に限定。

### コントラスト検証済みの組み合わせ

- `#15365c` on `#faf9f6` / `#ffffff` / `#dfeef7` — AA 以上
- `#647180` は 14px 以上の補足テキストのみ（`#faf9f6` 上で 4.6:1）
- `#d89a43` は白背景の本文には使わない（3:1 未満）。太字の大型数値・アイコン・ダーク面上のみ

## タイポグラフィ

- 本文: Noto Sans JP（400 / 500 / 700 / 900）— 既存を継続
- 見出しアクセント: **Noto Serif JP**（600 / 700）— ヒーロー・セクション見出しの一部にのみ使用
- 英数字: Noto Sans JP 内の欧文をそのまま使用（追加欧文フォントは読み込まない＝日本語フォントCSS肥大の回避）
- ヒーローは `clamp()` で 2〜4行以内。細すぎるウェイト（〜300）は使わない

## ブランド猫（統一キャラクター）

基準特徴（全イラスト共通・画像生成プロンプトにも必ず含める）:
白〜クリームの毛色 / 耳・顔まわり・しっぽに淡ベージュのポイント / 大きく丸い瞳 /
小さなピンクの鼻 / きょとんとした優しい表情 / 細長く上品な体つき / 細線・少色数・フラット寄り

- サイト実装は `CatIllustration`（シーン別SVG）と `CatAccent`（小アイコン）に集約し、同一の顔・配色定数を共有
- 使用箇所: ロゴ横 / ヒーロー / CTA / 404 / フッター / 流れの挿絵 — **全カード配置・肉球乱用・猫語多用は禁止**
- 猫語は吹き出し内の短い補足のみ。本文は通常の企業日本語
- ChatGPT 生成画像（webp）が用意され次第 `src/config/images.ts` のパスを差し替えれば SVG から置換される

## モーション

- フェードイン + 8px 浮き上がり（IntersectionObserver、CSS クラス付与のみ）
- カードホバー: `translateY(-4px)` + シャドウ
- `prefers-reduced-motion: reduce` で全停止（既存実装を維持）
- 跳ねる・走る・常時動作・パララックスは禁止

## レイアウト

- コンテナ: `max-w-6xl`、セクション縦 padding `py-20 sm:py-28`（既存踏襲）
- カード角丸: `rounded-2xl`、面は `--color-surface` + `--color-border`
- タップ領域 44px 以上 / フォーカスリングは primary
- 確認ブレークポイント: 375 / 390 / 430 / 768 / 1024 / 1280 / 1440 / 1920px
